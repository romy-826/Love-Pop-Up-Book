# 缠绕 · 我们的纪念册

绿色丝绒封面、古典手工纸、蕾丝与花枝；五组内页包含日期、抽拉照片、回忆卡片、立体相框、可编辑信件及流动红线。纯 HTML / CSS / JavaScript，不需要安装依赖或运行构建。

## 上传 GitHub 并打开网页

1. 解压项目 ZIP。把本文件旁的 `index.html`、`art.js`、`art.css`、`style.css`、`assets/`、`story.json` 等文件上传到 GitHub 仓库根目录。不要只上传 ZIP，也不要把整个项目额外套在一层文件夹里。
2. 在仓库 **Settings → Pages** 中，Source 选择 **Deploy from a branch**，分支选择 **main**，目录选择 **/(root)**，点击 **Save**。
3. 等待 Pages 部署完成，使用设置页显示的网址访问。仓库名称可以自定义，图片与脚本均使用相对路径。

设置方式见 [GitHub 官方说明](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)。

## 照片与文字

- 点击“写下我们的故事”可修改名字、主题、日期、信件、纸张留言和九个照片位置。
- 第三组跨页左侧的爱心相框可直接点击上传照片，下方纸张可直接输入文字并自动保存。
- 回忆卡片点击后展开，再次点击收回；照片以完整画面显示，比例不同会保留留白。
- 日历页抽拉照片在收拢时完全隐藏，拉至最右侧显示完整图片；可以点击“收回”。
- 心动进度支持鼠标拖动、触屏拖动和键盘方向键；数值会保存。
- 直接点击书页空白处：右页翻到下一组，左页翻到上一组；第一页的左页可以返回封面。日期、相框、信件和输入框等交互区域优先操作自身，不会触发翻页。
- 点击封面时沿书脊掀开，内页带翻纸动画。封面的松散丝带持续起伏，固定在书上的部分保持稳定；系统选择“减少动态效果”时停用这些动画。

编辑默认保存在当前浏览器。**把网页源码上传 GitHub 不会自动带上浏览器中已填写的照片和文字。**

想让其他人看到你填写的内容：打开编辑面板，点击 **导出发布内容**，得到 `story.json`，用它替换仓库根目录下的同名文件并提交。新访客会读取这份内容；已有本地编辑的浏览器继续保留自己的编辑。换新浏览器或无痕窗口可核对发布内容。备份的导入/导出也会保留爱心相框和纸张留言。

## 本地预览与检查（可选）

安装 Node.js 后，在项目目录执行：

```sh
npm start
```

访问终端显示的本机地址。没有依赖，无需 `npm install`。源码检查：

```sh
npm run check
```

## 文件结构

```text
index.html       页面与编辑表单
art.js           状态、机关、照片与内容保存
art.css          当前展示及交互样式
style.css        基础排版、表单和弹窗样式
assets/          本地图片素材
story.json       给新访客展示的默认内容
tools/           可选的本地预览及检查脚本
.nojekyll        静态文件直接发布标记
```

效果使用原图、局部动态和 CSS 立体机关组合，属于静态网页，无服务器数据库。
